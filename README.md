# ExpenseFlow

Free personal expense tracker with weekly and monthly spending summaries.

## Features

- 📊 **Automatic Calculations** - Weekly, monthly, and all-time expense totals
- 🔐 **Secure Authentication** - User accounts with Supabase
- 🌙 **Beautiful Dark UI** - Premium design inspired by Apple & Google
- 📱 **Mobile Friendly** - Works perfectly on Android & iOS
- ☁️ **Cloud Sync** - Access your data from any device

## Live Demo

**[Try ExpenseFlow →](https://akshat-agrawal18.github.io/expense-flow/)**

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- Supabase (Authentication + PostgreSQL Database)
- GitHub Pages (Hosting)

## Local Development

1. Clone this repository
2. Open `index.html` in your browser
3. Create a Supabase project and update credentials in `script.js`
